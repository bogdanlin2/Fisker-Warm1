# Fisker Warm Lab 0.3 — PKC Offline Lab + Climate Monitor

Дослідницька Android-програма для **власного Fisker Ocean Extreme 2023 (EU)** і адаптера **Vgate vLinker FD+ Bluetooth LE**. Побудована з вихідного коду версії 0.1.1. У жовтні 2026 попередній APK 0.1.0 уже читав чотири ECU та GATT на машині; **новий режим 0.2 ще не перевірений на авто**.

## Що нового у 0.3.0

Додано **офлайн-модуль** `PkcOfflineCodec`: синтетичні кліматичні payload, кодування температур 18–32 °C, перевірений HMAC-SHA256 і розбір окремих кодів стану згідно зі статичним звітом OceanLink Pro 1.2.6. **Не додається BLE GATT sender чи доступ до ключа. Опалення не запускається.** Деталі та обмеження у `docs/PKC-OFFLINE-0.3-UA.md`.

## Можливості

1. Зчитування напруги адаптера в OBD (`ATRV`) — це **не** стан заряду HV або здоров'я 12V.
2. Читання підтверджених ідентифікаторів PKC/ECC/BCM/ICC.
3. Читання BLE GATT структури без значень і запису.
4. **Новинка:** короткий запис пасивних CAN-кадрів за вимкненого клімату та за увімкненого вручну, порівняння ID і локальний JSON.

**Ця програма не знає, який саме CAN ID керує обігрівом.** Будь-яка зміна ID може бути стороннім таймером, лічильником, іншою системою автомобіля. Якщо OBD-шлюз не пропускає пасивні кадри, результатом буде «0 кадрів» — це не помилка Bluetooth і не підстава вгадувати UDS-команди.

## Інструкція на автомобілі

- Постав машину в **P** та залишся поруч, увімкни її штатно ключем; переконайся, що заряд 12 V нормальний. Для записів з низькою/невідомою напругою блоковано будь-яку CAN/UDS активність.
- Вимкни клімат на екрані автомобіля.
- Постав прапорець «Авто стоїть у P», натисни **1. Записати CAN · клімат ВИМКНЕНО**, обери тільки свій vLinker FD-IOS. Зачекай завершення.
- Увімкни обігрів вручну штатним меню машини. **Не змінюй режим руху; не їдь.**
- Протягом 15 хвилин натисни **2. Записати CAN · клімат УВІМКНЕНО**. Збережи отриманий JSON; він містить `baseline` та `comparison`, якщо умови виконано.
- Якщо бачиш «NO_PASSIVE_FRAMES», запиши JSON і не повторюй циклічно: можливо, OBD-шлюз не пропускає пасивні широкомовні дані.
- Натисни «Зупинити й роз'єднати» та закрий застосунок.

## Правила безпеки

- Немає мережевих дозволів, фонового сервісу, планування запусків або зняття блокувань.
- `ATMA` та налаштування ELM лише слухають CAN; не надсилається жоден UDS-запит у пасивному режимі. Один сеанс до 60 сек, відбір CAN 4 секунди, максимум 48 KB в оперативній пам'яті.
- Підпис BLE descriptor використовується лише для отримання відповідей від адаптера. Це **не команда для автомобіля**.
- Невідомі або низькі значення напруги блокують ECU/CAN-запити. Показник `ATRV` сам по собі не доводить здоров'я акумулятора.
- Офіційна/достовірна команда HVAC start, wake, status та автомобільний таймаут не встановлені; запуск обігріву залишено вимкненим.
- Експортуй журнал обережно: CAN-кадри можуть містити непрямі дані про автомобіль.

## Збирання

Залежності: JDK 17+, **офіційний Android SDK Platform 35** і **Build Tools 35.0.0** (`aapt2`, `zipalign`, `lib/d8.jar`, `lib/apksigner.jar`). Зовнішні бібліотеки і Gradle не потрібні.

```sh
python3 scripts/test_core.py
export ANDROID_SDK_ROOT=/path/to/android-sdk
python3 scripts/build_android.py
```

Очікуваний APK після збирання: `dist/Fisker-Warm-Lab-0.3.0.apk`.

**Для створення APK потрібен встановлений Android SDK; наявність APK залежить від середовища збірки.** Для APK передай ZIP до ChatGPT Work, який має Android SDK, або відкрий у Linux із SDK. Новий Android package `com.fiskerwarm.lab03` дає змогу встановити додаток поруч зі старим, навіть коли APK підписані різними ключами.

## Джерела та обмеження

- Реальні журнали власника від 12.10.2026 `IDENTITIES_CAPTURED`, `GATT_MAP_CAPTURED`.
- Публічні [Fiskeretta Diagnostics](https://github.com/Fiskeretta/fiskeretta-diagnostics) і [puddletools/CAN](https://github.com/puddletools/CAN) підтверджують підходи до діагностики; **не** підтверджують команд керування HVAC.
- Неточні або запозичені UDS-DID інших марок навмисно не використовуються.
