# PKC / Fisker Warm Lab 0.3.0 — офлайн-дослідження

**12 жовтня 2026. Не перевірено на автомобілі.**

Джерело статичних фактів: `OceanLink-Pro-1.2.6-Report-UA.pdf` та `OceanLink-Pro-1.2.6-Analysis-UA.zip`, проаналізовані окремо. Версія 0.3.0 **не** включає чужого SDK, декомпільованих методів чи пропрієтарної реалізації. Код написаний незалежно за описом сумісності.

## Що додано

- `PkcOfflineCodec.java` — незалежні чисті функції для **синтетичних офлайн-тестів**: базові шестибайтові payload start/stop, зафіксовані значення тривалості, кодування температури 18–32 °C кроком 0,5 °C, окремі статус-поля 0x57/58/59/5A/5B/5F та HMAC-SHA256 на штучних ключах.
- Додаткові тести для RFC 4231 HMAC, меж, некоректних запитів, температур, статусів та неможливості передачі у автомобіль.
- Інформаційний блок на екрані: це дослідження, запуск опалення недоступний.

**Знайдені payload — це НЕ повні пакети Bluetooth і НЕ команди для адаптера vLinker.** Критично не відновлено авторизований ключ власника/ключовий provisioning, challenge/freshness для реального з'єднання, повну специфікацію BLE GATT та життєвий цикл підключення, пробудження сплячого PKC і надійний автомобільний таймаут.

## Що навмисно не додано

- Жодних дозволів `BLUETOOTH_ADVERTISE`, `INTERNET`, Android foreground service / alarms, BLE GATT-server та мережевого шлюзу.
- Жодного прямого виклику `sendDataToPKC`, передачі payload, температури або ключів у машину.
- Жодних нових UDS DID/CAN-ID, write/session/security-access команд.
- Не змінено `ReadOnlyPolicy.java`, `HeatSafety.java` та їхні обмеження.
- Не витягаємо ключі з чужих акаунтів, не вимикаємо ліцензійних перевірок.

## Потрібні докази до наступної фази

1. Власний VA/BLE-key, отриманий тільки через дозволений власнику спосіб, із захищеним зберіганням та без логування.
2. Повна власна специфікація локального BLE протоколу і тест handshake зі статусами **без команд клімату**.
3. Підтвердження конкретно на PKC 21.3, що статуси свіжі, авто стоїть у P, HVAC має fail-safe timeout.
4. Тести wake із замкненого сну без впливу на 12 V.
5. Лише після цього — окремий дозвіл на контрольовані випробування.

Версія 0.3.0 є **офлайн-інструментом**, не готовою програмою обігріву. Зібраний APK, якщо він буде створений, ще має пройти перевірку підпису й не вважається протестованим на авто.
