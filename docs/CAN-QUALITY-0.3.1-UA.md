# CAN 0.3.1 — виправлення оцінки якості

Фактичний тест 12.10.2026: OFF 46 кадрів, ON 45 кадрів, лише ID 0E9, в обох записах `adapterBufferFull=true`. Відмінність не доводить зв’язок із HVAC.

Зміни: порівняння позначається `usable=false`, коли хоча б один запис переповнений чи обрізаний; додається `captureIncomplete` та `captureQuality`. Рядок BUFFER FULL не рахується як сторонній кадр.

**Не виправлено:** апаратне переповнення ELM-буфера. Не збільшено час моніторингу, не змінено CAN/UDS дозволи, не додано команди. Для майбутнього покращення потоку потрібна окрема перевірка безпечного потокового парсера.

Це патч вихідного коду, не підписаний APK.
