# Відновлення підпису com.fiskerwarm.lab03

Для наступних оновлень потрібно використовувати той самий ключ підпису APK. Це ключ Android-застосунку; він не є автомобільним BLE/VA-key.

Матеріал підпису збережений окремо від вихідного ZIP у власницьких файлах:

- `Fisker-Warm-Lab03-Signing-Key.p12` - зашифрований PKCS12, alias `lab`, RSA 3072.
- `Fisker-Warm-Lab03-Signing-Password.bin` - окремий файл із паролем; вміст не включений у цей проєкт чи журнали.

Ключ PKCS12 захищений випадковим паролем. Перевірено PBES2 / PBKDF2 / AES-256-CBC та MAC SHA-256, 10 000 ітерацій. Робочі файли мають права 0600, приватний каталог - 0700.

Відбиток сертифіката SHA-256:

`3c1716e279eb2a9cfc8b1c90d54845a2cb74a92ecc1df3bf2dc0955a2b39be74`

Публічний сертифікат: `verification/0.3.0-build/signer-certificate.pem`. Він не містить приватного ключа.

## Перед майбутньою збіркою

1. Отримати обидва власницькі файли локально; не додавати їх до репозиторію, вихідного ZIP або журналів.
2. Створити приватний каталог `build/` у корені проєкту. Скопіювати PKCS12 як `build/local-lab-signing.p12`, файл пароля - як `build/.local-signing-password`.
3. Встановити права 0700 для `build/`, 0600 для двох файлів. Зберегти резервні копії окремо.
4. Перевірити збіг публічного сертифіката зі вказаним відбитком. Не замінювати наявний ключ випадковим новим.
5. Запустити штатні тести й `scripts/build_android.py` з офіційним SDK. Скрипт використає наявний ключ. Для справжнього оновлення потрібно належно збільшити versionCode, зберігаючи applicationId та ключ; це не виконувалося у поточному завданні.

У версії 0.3.3 штатний скрипт зупиняється, якщо ключ або пароль відсутні, та перевіряє відбиток сертифіката перед підписом. Новий ключ автоматично не генерується. Спочатку потрібно відновити власницький матеріал підпису.

Для GitHub Actions потрібні repository secrets `FISKERWARM_KEYSTORE_B64` та `FISKERWARM_SIGNING_PASSWORD`; значення й ключ не можна додавати до репозиторію, артефактів або кешу. Workflow відновлює їх у тимчасові файли з правами 0600 і видаляє після збірки.
