# Fisker Warm Lab 0.3.3 — короткий CAN-запис

- Скорочено одне пасивне вікно з 4 с до 0.5 с, щоб зменшити ризик переповнення внутрішнього буфера ELM.
- Монітор припиняється достроково при BUFFER FULL або обрізанні; ознаки неповного запису залишаються в JSON.
- Це експериментальна зміна, не гарантія усунення переповнення. Для надійного декодування потрібні повні записи та повторні OFF/ON спостереження.
- Жодних команд клімату чи нових CAN/UDS запитів.
