# Fisker Warm Lab

Android-дослідження Fisker Ocean Extreme 2023 EU. Підготовлений вихідний пакет: **0.3.2**.

## Статус

Перенесення вихідного коду 0.3.2 ще не завершене. APK тут поки немає.

## Безпека

Read-only діагностика. Не додавати неперевірені UDS/CAN/HVAC-команди та не змінювати `ReadOnlyPolicy` або `HeatSafety` без окремої перевірки. Дистанційний запуск обігріву не реалізований і не випробуваний на автомобілі.
